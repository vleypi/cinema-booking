# 1 Общие сведения

## 1.1 Объект тестирования

Объектом тестирования являются результаты этапа 3 плана-графика:

- серверное API публичного каталога, бронирования мест, оплаты через ЮKassa, генерации PDF-билетов с подписанным QR-кодом, фоновой отправки писем через BullMQ, входа клиента по одноразовому коду и личного кабинета;
- клиентское приложение для зрителей (`frontend/cinema`): афиша, расписание, раздел «Скоро в прокате», страница фильма, интерактивная схема зала с оформлением заказа, страница подтверждения, вход по OTP и личный кабинет.

# 5 Найденные дефекты

Найденные и исправленные в ходе тестирования этапа 3 дефекты приведены в таблице 7.

Таблица 7. Найденные дефекты

| № | Описание | Требование | Серьезность | Статус |
|---|---|---|---|---|
| Д-1 | На ширине 360 px страница фильма (`/films/[id]`) имела горизонтальную прокрутку (+208 px) из-за неявного размера колонки CSS Grid | NFR-20 | Средняя | Исправлен |

Для исправления Д-1 и Д-2 добавлены `grid-cols-1` и `min-w-0` на контейнеры `FilmView`, `FilmSessions`, `SessionBookingView` и `SeatMap`. Повторный прогон Playwright подтвердил нулевое переполнение (`0 px`) на всех проверяемых маршрутах.

# 6 Ограничения проверки
