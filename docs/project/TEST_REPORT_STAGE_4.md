# 1 Общие сведения

## 1.1 Объект тестирования

Объектом тестирования являются результаты этапа 4 плана-графика:

- серверное API кассовых продаж и печати билетов (A4 и чековая лента 80 мм), поиска заказов, проверки и гашения билетов на входе (QR-код с HMAC-подписью и ручной ввод 10-символьного кода), возвратов билетов (личным кабинетом, одноразовой ссылкой из письма и в кассе), отмены сеанса с массовым возвратом, отчётов по выручке и заполняемости и журнала аудита;
- приложение для сотрудников (`frontend/crm`): раздел «Касса» (продажа без лимита 5 мест, печать A4 и 80 мм, поиск и возврат заказов), раздел «Сканер билетов» (камера `html5-qrcode`, ручной ввод кода, выбор зала, полноэкранный экран результата), отмена сеанса в «Расписании», разделы «Отчёты» и «Журнал аудита»;
- клиентское приложение для зрителей (`frontend/cinema`): возврат активных билетов в личном кабинете (`/cabinet`) и публичная страница возврата по одноразовой ссылке из письма (`/refund`).

Тестировалась ветка `main` на коммите `fe063c3` вместе с изменениями задачи 4.9.
